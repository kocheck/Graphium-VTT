# Graphium VTT support

Graphium is a virtual tabletop for the Mac. The Dungeon Master builds and runs the map in one window while players watch a second window on the TV or projector. Campaigns are files you own, and nothing leaves your Mac unless you ask.

This repository holds Graphium's public support site and issue tracker. The app's source isn't here.

- **Support:** https://getgraphium.com/support
- **Privacy policy:** https://getgraphium.com/privacy
- **Report a bug or request a feature:** [open an issue](https://github.com/kocheck/graphium-vtt/issues/new/choose). Issues are public, so check screenshots and attachments for anything you'd rather keep private.
